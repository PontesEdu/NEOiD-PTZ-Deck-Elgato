NEOiD PTZ Deck - Select Camera PTZ

🇧🇷 Português:

Para controlar uma câmera PTZ, primeiro registre a câmera informando o endereço IP no campo Camera IP e, se desejar, atribua um nome no campo Name. Caso a câmera adicionada não esteja conectada, o sistema exibirá automaticamente Not connected no lugar do nome. Sempre que for controlar uma câmera, certifique-se de selecioná-la aqui.

Se a opção NEOiD By Telycam estiver ativada, serão exibidos os campos User e Password. Após informar as credenciais, o sistema verificará automaticamente se a câmera está conectada.
⚠️ Importante: para utilizar qualquer ação com câmeras Telycam, a opção NEOiD By Telycam deve estar ativada nesta ação. Sem essa opção ativa, não será possível controlar câmeras Telycam.

🇺🇸 English:

To control a PTZ camera, first register it by entering the camera IP address in the Camera IP field and optionally assigning a name in the Name field. If the added camera is not connected, the system will automatically display Not connected instead of the name. Whenever you want to control a camera, make sure to select it here.

When the NEOiD By Telycam option is enabled, the User and Password fields will appear. After entering the credentials, the system will automatically check whether the camera is connected.
⚠️ Important: to use any action with Telycam cameras, the NEOiD By Telycam option must be enabled in this action. Without it, Telycam cameras cannot be controlled.
