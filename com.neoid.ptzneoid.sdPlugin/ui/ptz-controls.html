NEOiD PTZ Deck - Controls PTZ

🇧🇷 Português:

Para usar os controles PTZ, primeiro escolha a direção para mover a câmera, como Home, Cima, Baixo, Esquerda, Direita ou opções Diagonais. Em seguida, pressione o botão para executar o movimento.

Ao ativar a opção Camera IP Default, será exibido um campo para inserir o IP da câmera. Após informar um IP válido, a ação exibirá o título Default e os controles PTZ passarão a operar exclusivamente a câmera definida nesse campo, ignorando a seleção do menu Select Camera.
⚠️ Importante: o Camera IP Default não é compatível com câmeras NEOiD By Telycam. Para controlar uma câmera NEOiD By Telycam, é obrigatório selecionar a opção NEOID by Telycam na ação Select Camera.

🇺🇸 English:

To use the PTZ controls, first choose the direction you want the camera to move, such as Home, Up, Down, Left, Right, or Diagonal options. Then press the button to perform the movement.

When the Camera IP Default option is enabled, a field will appear allowing you to enter the camera IP. After providing a valid IP, the action will display the Default title, and the PTZ controls will operate only the camera specified in this IP field, ignoring the Select Camera menu.
⚠️ Important: Camera IP Default is not compatible with NEOiD By Telycam. To control a Telycam camera, you must select NEOID by Telycam in the Select Camera action.
